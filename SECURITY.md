# Security Policy

## Reporting security issues

Please do **not** publish security vulnerabilities, credentials, private user
data, authentication details, or exploit instructions in public GitHub Issues.

Report security-sensitive findings privately to the repository owner through
GitHub.

When possible, include:
- the affected area,
- reproduction steps,
- potential impact,
- suggested mitigation.

## Public showcase scope

This repository is for public product documentation and feedback only. It does
not contain the Aqua Nexus production source code.

Never post API keys, passwords, tokens, database credentials, private aquarium
exports, or personal information in public issues.
